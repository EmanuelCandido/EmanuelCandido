### Pesquisa

**Iniciação científica (PIBIC)**, Centro Universitário Santo Agostinho · mar. 2026 – atual

[ClinicCase](https://github.com/EmanuelCandido/ClinicCase): geração de casos clínicos e perguntas
avaliativas com LLM e recuperação de contexto (RAG), para o ensino em saúde. O professor define a
especialidade, o diagnóstico esperado e o objetivo de aprendizagem; a plataforma gera o caso em cerca
de 20 segundos, e o professor revisa e publica.

- Sou responsável pelo back-end: API REST em Spring Boot, autenticação JWT com Spring Security,
  integração com o modelo via Spring AI e 23 migrações versionadas com Flyway.
- A API valida a coerência clínica antes e depois da geração, registra a proveniência do conteúdo
  gerado e deixa as respostas discursivas para revisão humana do professor.
- Trabalho apresentado no **Opala Tech V** (IFPI) e no **DELTA Saúde 2026**. Em produção em
  [cliniccase.site](https://cliniccase.site).
